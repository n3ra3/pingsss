# Steam buy-order watcher (Telegram bot)

Ты выставляешь **ордер на покупку** предмета по цене `X`. Если появляется
**лот на продажу по цене ≤ потолка выгоды** `X * (1 + N%)` (в том числе дешевле
твоего ордера) — бот пингует тебя в Telegram, чтобы ты купил его вручную. Каждый
новый лот пингуется один раз — без спама на каждый прокрут.

Данные берутся из публичного эндпоинта Steam `priceoverview` (самая низкая цена
продажи + объём). Ничего в Steam не пишется — только чтение, аккаунт в безопасности.

## Как это работает

- Кидаешь боту **ссылку на предмет + цену своего ордера** (плюс, по желанию,
  потолок в `%` или абсолютным максимумом).
- Бот раз в `POLL_INTERVAL` секунд опрашивает Steam по каждому предмету.
- Как только самый дешёвый лот оказывается на уровне `потолок` или ниже — приходит
  уведомление. Пока цена того же лота не меняется — молчит. Лот ушёл и вернулся
  новый — пингует снова.

## Команды бота

```
<ссылка> <цена ордера> [+N%] [макс. цена]
```

Примеры:
```
https://steamcommunity.com/market/listings/730/AK-47%20%7C%20Redline%20(Field-Tested) 12.50
https://steamcommunity.com/market/listings/730/AK-47%20%7C%20Redline%20(Field-Tested) 12.50 8%
https://steamcommunity.com/market/listings/730/AK-47%20%7C%20Redline%20(Field-Tested) 12.50 14.00
```

- Первое число — цена твоего ордера.
- `N%` — потолок над ордером. Второе число без `%` — абсолютный максимум.
- Без потолка берётся `DEFAULT_MARGIN_PCT` (по умолчанию +10%).

Ещё: `/list` — список, `/remove N` — убрать предмет №N, `/help` — справка.

## Переменные окружения

| Переменная | Обязательна | Значение |
|---|---|---|
| `BOT_TOKEN` | да | токен бота от @BotFather |
| `OWNER_CHAT_ID` | желательно | твой Telegram chat_id (бот подскажет, см. ниже) |
| `DATABASE_URL` | на Render — да | `postgres://...` (Neon/Supabase). Пусто = локальный SQLite |
| `CURRENCY` | нет | `1` = USD (по умолчанию) |
| `DEFAULT_MARGIN_PCT` | нет | потолок над ордером в %, по умолчанию `10` |
| `POLL_INTERVAL` | нет | секунд между полными циклами, по умолчанию `90` |
| `REQUEST_DELAY` | нет | секунд между запросами по предметам, по умолчанию `4` |
| `PORT` | нет | порт `/health` (Render задаёт сам) |

## Локальный запуск (тест)

```bash
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...      # в PowerShell: $env:BOT_TOKEN="..."
python bot.py
```

Напиши боту `/start` — он ответит и покажет твой `chat_id`. Впиши его в
`OWNER_CHAT_ID` и перезапусти, чтобы боту мог писать только ты. Без
`DATABASE_URL` данные лягут в локальный `data.db`.

## Деплой на Render (бесплатно, 24/7)

1. **Бот в Telegram.** Напиши @BotFather → `/newbot` → получи `BOT_TOKEN`.

2. **База (чтобы список не терялся при рестартах).** Заведи бесплатную Postgres
   на [neon.tech](https://neon.tech) (или Supabase). Скопируй строку подключения
   вида `postgres://user:pass@host/db` — это `DATABASE_URL`.
   > На бесплатном Render файловая система эфемерна, поэтому SQLite там сбрасывается
   > при каждом редеплое. Postgres решает это.

3. **Render.** Залей эту папку в GitHub-репозиторий, затем на
   [render.com](https://render.com) → **New → Web Service** → выбери репозиторий.
   `render.yaml` уже задаёт сборку и запуск. В разделе **Environment** пропиши:
   `BOT_TOKEN`, `OWNER_CHAT_ID`, `DATABASE_URL` (остальное — по вкусу).
   Health check path: `/health` (уже в конфиге).

4. **UptimeRobot** (чтобы инстанс не засыпал). На
   [uptimerobot.com](https://uptimerobot.com) → **Add New Monitor** →
   тип **HTTP(s)** (HEAD-запрос) → URL `https://<твой-сервис>.onrender.com/health`
   → интервал **5 минут**. Так Render не уходит в сон.

Проверить, что живо: открой `https://<сервис>.onrender.com/health` — вернётся JSON
со статусом, числом предметов и временем последнего опроса.

## Про лимиты Steam

`priceoverview` жёстко лимитирован (примерно ~20 запросов в минуту с одного IP,
при превышении — временный бан). Настройки по умолчанию (`POLL_INTERVAL=90`,
`REQUEST_DELAY=4`) держат нагрузку низкой. Если следишь за многими предметами
(20+), увеличь `POLL_INTERVAL` до 150–180, иначе получишь 429 и пропуски циклов
(бот их молча переживает и не шлёт ложных «вне диапазона»).

## Важно

Бот **только читает** цены и шлёт уведомления. Покупка/выставление ордеров идёт
руками через Steam. Автотрейд-ботами Steam банит аккаунты — здесь этого нет.
