# Steam → PirateSwap arbitrage watcher (Telegram bot)

Кидаешь боту **ссылку на предмет Steam Market** — он берёт **нижнюю цену Steam**
(во сколько обойдётся купить) и **цену на PirateSwap за вычетом `PS_FEE_PCT`**
(по умолчанию −10%, за сколько реально продать) и пингует в Telegram, когда
профит `(PS×0.9 − Steam) / Steam` достигает порога (по умолчанию **20%**).

Источники данных (только чтение, ничего не пишется):
- **Steam** — `market/search/render` (нижняя цена активного лота). Валюту эндпоинт
  определяет по региону IP; бот доверяет цене только в USD (`$`), иначе пропускает.
- **PirateSwap** — публичный `web.pirateswap.com` (`autocomplete` → коды скина,
  `ExchangerInventory` → цена). Логин не нужен.

## Как это работает

- Кидаешь **только ссылку** (можно с числом-порогом в конце, напр. `... 25`).
- Бот один раз находит предмет на PirateSwap (по имени → хеш-код экстерьера) и
  запоминает код.
- Раз в `POLL_INTERVAL` секунд считает профит. Достиг порога — пинг. Пока цена
  Steam не сдвинулась — молчит (без спама). Профит ушёл ниже порога и вернулся —
  пингует снова.

## Команды бота

```
<ссылка на предмет Steam Market> [порог %]
```

Примеры:
```
https://steamcommunity.com/market/listings/730/AK-47%20%7C%20Redline%20(Field-Tested)
https://steamcommunity.com/market/listings/730/AK-47%20%7C%20Redline%20(Field-Tested) 25
```

- Без числа берётся `DEFAULT_PROFIT_PCT` (по умолчанию 20%).
- Число после ссылки — свой порог профита для этого предмета.

Ещё: `/list` — список, `/check` — посчитать сейчас, `/remove N` — убрать, `/help`.

## Переменные окружения

| Переменная | Обязательна | Значение |
|---|---|---|
| `BOT_TOKEN` | да | токен бота от @BotFather |
| `OWNER_CHAT_ID` | желательно | твой Telegram chat_id (бот подскажет, см. ниже) |
| `DATABASE_URL` | на Render — да | `postgres://...` (Neon/Supabase). Пусто = локальный SQLite |
| `CURRENCY` | нет | `1` = USD (по умолчанию) |
| `DEFAULT_PROFIT_PCT` | нет | порог профита Steam→PirateSwap в %, по умолчанию `20` |
| `PS_FEE_PCT` | нет | вычет из цены PirateSwap перед расчётом профита, по умолчанию `10` |
| `POLL_INTERVAL` | нет | секунд между полными циклами, по умолчанию `90` |
| `REQUEST_DELAY` | нет | секунд между запросами по предметам, по умолчанию `4` |
| `PORT` | нет | порт `/health` (Render задаёт сам) |

## Локальный запуск (тест)

```bash
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...      # в PowerShell: $env:BOT_TOKEN="..."
python bot.py
```

Напиши боту `/start` — он ответит и покажет твой `chat_id`. Впиши его в
`OWNER_CHAT_ID` и перезапусти, чтобы боту мог писать только ты. Без
`DATABASE_URL` данные лягут в локальный `data.db`.

## Деплой на Render (бесплатно, 24/7)

1. **Бот в Telegram.** Напиши @BotFather → `/newbot` → получи `BOT_TOKEN`.

2. **База (чтобы список не терялся при рестартах).** Заведи бесплатную Postgres
   на [neon.tech](https://neon.tech) (или Supabase). Скопируй строку подключения
   вида `postgres://user:pass@host/db` — это `DATABASE_URL`.
   > На бесплатном Render файловая система эфемерна, поэтому SQLite там сбрасывается
   > при каждом редеплое. Postgres решает это.

3. **Render.** Залей эту папку в GitHub-репозиторий, затем на
   [render.com](https://render.com) → **New → Web Service** → выбери репозиторий.
   `render.yaml` уже задаёт сборку и запуск. В разделе **Environment** пропиши:
   `BOT_TOKEN`, `OWNER_CHAT_ID`, `DATABASE_URL` (остальное — по вкусу).
   Health check path: `/health` (уже в конфиге).

4. **UptimeRobot** (чтобы инстанс не засыпал). На
   [uptimerobot.com](https://uptimerobot.com) → **Add New Monitor** →
   тип **HTTP(s)** (HEAD-запрос) → URL `https://<твой-сервис>.onrender.com/health`
   → интервал **5 минут**. Так Render не уходит в сон.

Проверить, что живо: открой `https://<сервис>.onrender.com/health` — вернётся JSON
со статусом, числом предметов и временем последнего опроса.

## Про лимиты Steam

Steam лимитирует рыночные эндпоинты **по IP**. Наши настройки по умолчанию
(`POLL_INTERVAL=600` — раз в 10 минут, `REQUEST_DELAY=8`) держат нагрузку
мизерной. Поймав 429, бот замолкает на `STEAM_COOLDOWN` секунд, чтобы лимит
сбросился, и не шлёт ложных сигналов.

⚠️ Главное: 429 почти всегда означает не «мы частим», а **грязный/общий IP**.
На бесплатном Render адрес общий и часто уже забит запросами других ботов —
тогда 429 будет даже при нашей редкой частоте. Кука (`STEAM_COOKIE`) для
`search/render` мало помогает (лимит по IP, не по аккаунту). Надёжнее всего —
**чистый резидентный IP**: домашний ПК или VPS с резидентным адресом.

## Важно

Бот **только читает** цены и шлёт уведомления. Покупка/выставление ордеров идёт
руками через Steam. Автотрейд-ботами Steam банит аккаунты — здесь этого нет.
